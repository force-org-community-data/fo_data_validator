# Example sources

Generic test sources. They reference no real game; they exist so every part of the data schema is exercised by the tests and by `npm run validate-data`.

- `starter/`: the smallest valid source (one game, one faction). Copy it to begin a new source.
- `full/`: uses every authorable schema field: terms, roles with grants, group types (root and linked), slot tags, list, unit and contingent resources, stat templates, list choices, every list rule kind (a faction rule and a sub-faction rule checked per group), detachments (requirements, limits, costs, `when`, `effects` in the `gun-line`), special rules (configurable, defaults, grants), named selectors, slot options (every effect kind), slots filled from elsewhere (a `source`: the `armoured-spearhead`'s and the `automata-handler` rule's slots draw on the second faction, `machine-cult`; `veterans`' `borrowed-specialists` slot option draws on every order of `field-army` with a selector `exclude` and a trait-replacing slot effect), sub-choices, units with every upgrade form, a unit with composition blocks (`gun-team`: a Gun Crew of a Gunner and a Loader, with per-profile default wargear; `sapper-team`: a Foreman block that `replaces` a Sapper), traits (on units, given, removed and replaced by trait effects, matched by selector `traits`), a faction upgrade referenced by units, a sub-faction with overrides and every unit modifier action, and sub-faction groups: `doctrine` (max 1; its two sub-factions reuse an id, which is fine because only one can be taken) and `heritage` (max as an expression; its two sub-factions share an identical rule, and one has a `when`; `assault-doctrine`'s `when` reads the main contingent with `main`). `veterans` and `extension/`'s `irregulars` have no `group`, so they're in the implicit `default` group.
- `extension/`: an extension source that adds a sub-faction to `full`'s game (`fo-validate examples/full examples/extension`).

`full` lists a placeholder in the manifest's `examples` field; the checker accepts the field but doesn't read the files. `grantedBy` is set by the Force Org app, not by authors, so no fixture uses it.
